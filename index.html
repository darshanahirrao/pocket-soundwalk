    Model, privacy & credits

    On-device, not infallible

    Audio Spectrogram Transformer (AST), trained on AudioSet's broad sound classes. Quantized open weights run in a browser worker through Transformers.js and ONNX Runtime. Scores are not calibrated probabilities. This is not a species identifier, safety detector or research instrument.

    Clips are decoded locally. Only the first 10 seconds are analyzed. Very quiet or clipped input is rejected before inference; uncertain results remain uncertain. Notes require your confirmation.

    Network & storage

    The first analysis downloads public model and runtime files from Hugging Face and its file-delivery hosts. Those hosts and GitHub Pages can see ordinary connection metadata. No audio, note text, account or precise location is sent by this app. No analytics. There is no offline-availability guarantee.

    Only confirmed note text and optional model scores are saved in this browser. Audio is held temporarily in memory and released when replaced or the page closes. Browser-data clearing removes the journal; export before clearing it.
